 Programación 1
Este repositorio contiene los programas y ejercicios
desarrollados durante la materia de Programación 1.
Los ejercicios están organizados por temas, y cada
programa se encuentra en su propia carpeta.
## Programas incluidos
### blakyak
Juego para una persona, compites contra la maquina, el que tenga o se acerque más a 21 gana.
### contra_segura
Lee el texto que le proporcionas como contraseña y determina si es segura.
### juego_luces
este programa te deja jugar un juego donde debes apagar todas las luces.
